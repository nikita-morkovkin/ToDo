# Little List

Небольшой адаптивный список дел на React, TypeScript, Vite и Tailwind CSS. Визуальный стиль вдохновлён Google Keep, с мягкой и минималистичной палитрой.

## Возможности

- Добавление задач и отметка их как выполненных или активных.
- Удаление отдельных задач и очистка всех выполненных задач.
- Фильтрация списка: все задачи, активные или выполненные.
- Автоматическое сохранение задач в `localStorage` браузера — список остаётся после перезагрузки страницы.
- Адаптивная вёрстка и элементы управления, доступные с клавиатуры.

## Локальный запуск

```bash
npm install
npm run dev
```

## Проверки

```bash
npm run lint
npm run build
```

## Деплой

Импортируйте репозиторий в Vercel. Это приложение Vite; команда сборки — `npm run build`, каталог результата — `dist`.

## ИИ-инструменты

Для помощи в реализации интерфейса и взаимодействия со списком задач использовался OpenAI ChatGPT. Корректность проверена сборкой TypeScript/Vite для production и ESLint.
